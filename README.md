# نظام عالم بيلسان — تأسيس البناء الآلي

هذا المستودع معدّ لبناء تطبيقَي Flutter للأندرويد:
- **عالم بيلسان:** `com.abumishal.kidslearn`
- **متابعة طفلتي:** `com.abumishal.parentcontrol`

## كيفية تشغيل أول بناء

1. **حوّل المستودع إلى Private قبل رفع الملفات.** الحزمة الأصلية تتضمن `google-services.json` الخاص بمشروعك.
2. من تبويب **Code** اختر **Add file > Upload files**، ثم ارفع ملف الحزمة `عالم_بيلسان_المراحل_01_03.zip` إلى **جذر المستودع**، مع الإبقاء على اسمه أو أي اسم ينتهي بـ`.zip`.
3. عند حفظ الـ commit سيعمل سير `Bilsan Android APK (ZIP source)` تلقائياً في تبويب **Actions**.
4. بعد نجاح التشغيل سيظهر ملفا APK في قسم **Artifacts**.

## ملاحظات مهمة

- الحزمة الحالية هي تأسيس المراحل 01–03 فقط، وليست تطبيقاً تعليمياً مكتملاً.
- لا ترفع مفتاح Gemini API ولا كلمات مرور أو رموز دخول إلى المستودع.
- القواعد الأمنية الحالية في المشروع مغلقة افتراضياً؛ المزامنة والربط الفعلي من مراحل لاحقة.
- سير البناء يستخدم GitHub Actions، ولا يستلزم تشغيل Flutter على جوالك.
